HOW TO USE
==========

1. Open in draw.io:
   https://app.diagrams.net → File → Open → SPMv3.0_Architecture.drawio

2. Or drag file to:
   https://app.diagrams.net

3. View the 4 architectural layers:
   - Layer 1 (Blue): Frontend React
   - Layer 2 (Orange/Purple/Green): Backend Flask
   - Layer 3 (Red): Databases
   - Layer 4 (Violet): External Services

4. Search components:
   Ctrl+F to find modules, services, or routes

5. Export:
   File → Export as → PNG/SVG/PDF
