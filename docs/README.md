# Documentacion SPM v2.0

> Sistema de Planificacion de Materiales

## Inicio Rapido

Para comenzar a desarrollar, consulta primero el archivo [`CLAUDE.md`](../CLAUDE.md) en la raiz del proyecto.

```bash
# Backend (Flask)
python wsgi.py

# Frontend (React + Vite)
cd frontend && npm run dev
```
